# 홈 리디자인 방향 결정 (2026-08-05)

## 1. 감사 — 왜 이전 리디자인이 체감되지 않았나

origin/main 기준, 에디토리얼 리디자인 6병합(163963f..51e45c6)의 실측:

| 파일 | 변경 | 성격 |
|---|---|---|
| app.js | +571줄 | 검색·팔로우·발간물 서가·타임라인 = **기능** |
| index.html | 37줄 | 탭 1개·검색 다이얼로그 추가 — **홈 섹션 구조 불변** |
| style.css | +219줄 | 토큰·신규 컴포넌트 스타일 — 기존 레이아웃 규칙 불변 |

홈 화면(#view-news)의 DOM 순서·그리드·타이포 위계는 리디자인 전과 동일했다.
h1은 23~30px(--t-hero, 3ff0907 축소 결정), 카드 목록은 균일 폭, 사이드바는
1200px 미만에서 소멸. 8/3 교훈("색깔만 바꿨네" — 기능 존재 여부와 시안처럼
보이는지는 다른 판정)이 그대로 재현된 것.

## 2. 두 방향

### A — Editorial Intelligence (Stripe Press 축)
- 큰 헤드라인 + 넓은 여백, 텍스트·출처 중심, 리포트 물성 강조
- 장점: 현재 코드베이스의 괘선·개조식 어법과 연속적, 신뢰성 인상
- 단점: 지금 화면도 이미 '조용한 에디토리얼'이라 **또 체감 실패 위험**

### B — Dynamic Signal (Arqé 축)
- 초대형 날짜 마스트헤드, 번호 섹션(01~05), 비대칭 그리드, 다크 잉크 밴드
- 장점: 전후 차이가 3초 안에 보임. '실시간 산업 인텔리전스' 인상
- 단점: 과하면 브리핑 도구의 정보 밀도를 해침

## 3. 결정 — B의 골격 + A의 콘텐츠 규율

핵심 사용자는 원전·에너지 업계 실무자다. 아침에 열어 "오늘 무엇이 달라졌나"를
5초 안에 읽어야 한다. 그래서:

- **골격은 B**: 마스트헤드의 초대형 모노 날짜(콘텐츠와 연결된 타이포그래픽
  그래픽 — 장식 아님), 섹션 번호 01~05, Section 05 다크 잉크 밴드, 크기 대비.
- **내용은 A의 규율 유지**: 중복 표시 금지 원칙, 개조식 리드, 근거 우선.
  기존에 확정된 편집 판단(배지는 예외만, 선정 이유 비노출 등)은 그대로.

## 4. 구조 변경 — 히어로·선두 카드 통합

--t-hero ≤30 잠금(3ff0907)의 전제는 "h1이 선두 카드 제목의 복사본이라 같은
문장이 화면에 반복된다"였다. 이번 개편은 **히어로와 선두 카드를 Section 01
하나의 에디토리얼 유닛으로 합쳐** 중복 자체를 제거한다. 제목이 한 번만 서므로
디스플레이 크기(--t-display, 최대 60px)가 다시 정당해진다. 잠금 테스트는 새
전제(통합 유닛 + 모바일 폴드 예산)로 갱신한다.

## 5. 새 홈 구조

```
01 TODAY    마스트헤드(초대형 날짜+메타) + 디스플레이 헤드라인 + 선두 이슈 블록
02 변화     지금 달라진 이슈 — 첫 항목 대형, 나머지 압축 행(신문 편집면 대비)
03 브리핑   오늘 확인된 이슈 — 기존 도구(정렬·필터·보기) 유지
04 추적     대형 검색 진입 + 많이 등장하는 대상 칩(entities.json 재사용)
05 신호     다크 잉크 밴드 — 검증 분포 + 주간 흐름 + 발간물 서가 미리보기
            (1200px 미만에서 소멸하던 사이드바 해석 레이어의 복권 — 8/3 모바일
            감사 P0 해소)
```

데이터 신규 수집 0. 전부 이미 로드되는 JSON 재사용.

## 6. 완료 판정 실측 기준 (8/3 교훈)

- h1 실측: 30px → 데스크톱 1440에서 52px± (synthesis·issue 공통)
- 마스트헤드 날짜: 신설, 모노 72px+
- 홈 섹션 밴드: 배경 대비 밴드 2개 이상(마스트헤드·신호)
- 모바일 360: 가로 오버플로 0, 검증·주간 흐름 섹션 존재(이전: 소멸)
- 균일 카드 나열 제거: 02 섹션 첫 항목과 나머지의 크기 대비
