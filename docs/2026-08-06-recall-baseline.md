## 읽는 법

- **수집 실패 4건 중 3건이 국내**이고, 전부 네이버 경로가 담당해야 할 주제다
  (산업정책·전력요금·지역 수용성). `news_bot.py` 의 네이버 쿼리가 `-` 를 제외
  연산자로 쓰는데 네이버 API 는 그것을 추가 검색어로 결합한다 — 실측으로
  `계속운전` + 프로덕션 negative_terms 9개 = **0건**. 이것이 국내 수집의 병목이다.
- **수집된 3건도 온전하지 않다.** 하나는 해외 매체 경유(국내 관점·다출처 신호 상실),
  하나는 `noise` 분류. 즉 collect 43% 는 상한이지 실질이 아니다.
- **팍스는 discovery 의 존재 이유를 그대로 보여준다.** 기존 클러스터가 있고 상태가
  뒤집혔는데, 뒤집힌 사실을 실은 국내 보도(뉴시스 17:56·JTBC 19:58)가 안 들어왔다.
