# nuclens 시현회 준비 (2026-09-17, 실·처 단위)

> 이후 경영진 보고 예정 — 이번 시현은 실무 데모 중심, 품질 숫자는 경영진 단계 무기로 축적.

## 1. 데모 대본 (7~10분)

**오프닝 멘트 (30초)** — 문제부터:
"원자력·에너지 뉴스는 하루 수백 건이고, 아침 스크랩·개별 검색으로는 놓치는 게 생깁니다. 이걸 수집원 46곳에서 자동 수집→AI 선별→매일 아침 브리핑까지 무인으로 돌리는 시스템입니다. 두 달째 무인 운영 중입니다."

**동선 (클릭 순서)**:
1. **아침 텔레그램 카드** (폰 화면 또는 캡처) — "매일 07:25, 출근길에 이미 와 있습니다"
2. **오늘 탭** — 이슈 카드: 중요도·검증 배지·AI 표시 짚기. "AI가 쓴 문장엔 전부 AI 배지가 붙습니다 — 사실과 해석을 섞지 않습니다"
3. **이슈 상세** — 검증(공식 원문·독립 출처 수), 사건 타임라인, 관련 이슈. 진행 중 사안이면 **스토리**(60일 넘는 경과) 열기
4. **⭐ 보고서용 복사** — 킬러 데모: 이슈 하나를 개조식 초안으로 복사 → 사내 보고서 골격에 붙이기. "기사 읽기에서 보고서 초안까지의 거리를 줄이는 게 목적입니다"
5. **흐름 탭** — 주간 판세·이어지는 사안·일정 캘린더 (빠르게 훑기)
6. **클로징** — 숫자 카드(§2) + "질문 받겠습니다"

**시간 배분**: 1~2번 2분 / 3번 2분 / 4번 3분(핵심) / 5번 1분 / 클로징 1분

## 3. 예상 질문 답변 (실·처 레벨)

- **"틀린 정보가 나가면?"** → 사실(기사 요약)과 AI 해석을 분리 표시하고, 해석엔 전부 AI 배지. 검증 배지는 공식 원문·복수 출처 확인 기반. 원문 링크가 항상 붙어 검증 가능. (경영진 단계까지 재현율·사실성 측정 숫자 추가 예정)
- **"운영은 누가?"** → 현재 자동화 파이프라인 + 개발자 1인 관리. 공식화 시 계정·인프라 이관 방안 별도 보고. (솔직하게 — 숨기면 나중에 더 아픔)
- **"비용은?"** → 현재 0원(무료 티어). 사용량 증가 시 월 수만 원 수준 예상 — 정확 시나리오는 경영진 보고에 포함.
- **"차장님 것과는?"** → 같은 뿌리에서 상호 검증하며 발전 중 — 상대 개선점을 5차례 상호 반영. 경쟁이 아니라 이중화·교차검증 구조.
- **"신문스크랩이랑 뭐가 달라?"** → 대체가 아니라 보완 — 스크랩방의 선별을 시드로 활용 중이고, 해외·공식기관 원문처럼 스크랩이 못 닿는 영역을 자동으로 채움.
- **"우리 부서 업무에 어떻게 써?"** → 데모 4번이 답. + 아침 브리핑 구독(텔레그램).
