이 서비스에서 더 위험한 실패는 누락이 아니라 오병합입니다. 여기서 누른 것도 기본 파일을 덮지 않고 판정으로 쌓이며, 다음 빌드부터 적용됩니다. 이미 나간 회차의 카드는 바뀌지 않습니다.

묶인 기사와 그 근거 수치입니다. 떼어내면 앞으로 이 조합을 다시 붙이지 않습니다.

02 문턱 아래 — 붙었어야 했나

자동 병합 문턱 바로 아래에서 안 붙은 쌍입니다. 점수가 높은 순.
