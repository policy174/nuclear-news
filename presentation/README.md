# 발표자료 — 원자력 뉴스 봇에서 AI 정책 브리핑 플랫폼까지

학습동아리 공유용 웹 프레젠테이션 (크림 배경 · 터미널 창 카드 디자인, 시행착오 중심 구성).
브라우저만 있으면 실행됩니다 — 서버·설치·외부 라이브러리 불필요.

## 실행

`index.html` 을 더블클릭 (또는 브라우저로 열기). 그게 전부입니다.

```bash
start presentation/index.html      # Windows
```

## 조작

| 키 | 동작 |
|---|---|
| `→` `Space` `PageDown` | 다음 화면 |
| `←` `PageUp` | 이전 화면 |
| `Home` / `End` | 처음 / 끝 |
| `N` | 발표자 노트 열기/닫기 |
| `T` | 목차 (특정 화면 바로 이동) |
| `F` | 전체화면 발표 모드 |
| `Ctrl+P` | 인쇄 · PDF 저장 (가로 A4, 슬라이드당 1장) |
| `Esc` | 목차·노트 닫기 |

- 카드 아래: 이전/다음 버튼 + 점(도트) 클릭으로 바로 이동.
- URL 이 `#/7` 형태로 유지 — 새로고침해도 복원, 링크 공유 가능. 모바일 스와이프 지원.

## 실제 캡처 넣기 (권장)

`assets/` 폴더에 정해진 파일명으로 텔레그램 캡처를 넣으면 **자동으로 실물 이미지가 표시**됩니다.
없으면 실제 발송 내용을 재구성한 목업이 대신 뜹니다 (이미지 없이도 발표 가능).

파일명 목록과 어떤 캡처를 넣을지는 [assets/README.md](assets/README.md) 참조.
핵심 6장: 최신 브리핑 / 5월 알림 폭탄 / Gemini 호출 실패 / 영어 카드 / 국내 0건 / 피드백 버튼 24개.

## 내용 수정

**`slides.js` 하나만 고치면 됩니다.**

- 발표자 이름·날짜·제목: 상단 `CONFIG`.
- 화면별 제목·본문·발표자 노트: `DECK` 배열.
- `index.html` / `styles.css` / `app.js` 는 건드릴 필요 없음.

## 발표 운영

- 구성·용어 정리는 5번(봇 설명 직후)에 있음 — 표를 다 읽지 말고 핵심만 짚고 통과.
- 시간 배분 제안: 1~5번 5분 / 시행착오 6~9번 4분 / 10~13번 3분 / 14~16번 3분(+질문).

## 발표 전 체크리스트

1. `CONFIG.date` = 2026-07-30, `CONFIG.presenter` 확인 (변경 시 `slides.js` 상단).
2. `assets/` 에 캡처 6장 저장 (위 참조).
3. 화면 3 수치(459건 / 55% / 9건)는 2026-07-29 저장소 기준. 갱신하려면 프로젝트 루트에서:
   ```bash
   python - <<'EOF'
   import json, collections
   c = json.load(open('curated.json', encoding='utf-8'))
   imp = collections.Counter(v.get('importance') for v in c.values() if isinstance(v, dict))
   rows = [json.loads(l) for l in open('delivery_log.jsonl', encoding='utf-8') if l.strip()]
   print('수집·분류:', len(c), '| noise:', imp['noise'], '| 발송:', len(rows))
   EOF
   ```
4. `N` 키로 노트 열고 처음부터 끝까지 리허설 1회.

## 외부 공유 시 (익명화)

내부 동아리 발표는 그대로 사용해도 됩니다. 외부 공유 가능성이 있으면 `slides.js`에서 아래만 수정:

| 항목 | 위치 |
|---|---|
| 발표자명·소속 | `CONFIG.presenter` / `CONFIG.affiliation` |
| 구독자 수 | `tg()` 조각의 "구독자 5명" + 화면 3 불릿 |
| 운영 수치 | 화면 3 stats (459건 / 55% / 9건) — 필요 시 "수백 건 중 하루 한 자릿수"로 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 뼈대 (수정 불필요) |
| `slides.js` | **발표 내용 + 발표자 노트 (여기만 수정)** |
| `styles.css` | 디자인 (터미널 카드 · 크림 테마) |
| `app.js` | 슬라이드 엔진 |
| `assets/` | 실제 캡처 슬롯 (없으면 목업 폴백) |

## 원칙

- 이 폴더는 봇 코드와 완전히 분리 — 발표자료를 고쳐도 봇 동작에 영향 없음.
- 토큰·비밀번호·채팅 ID·저장소 주소는 어디에도 넣지 않음.
- 목업은 전부 "실제 발송 내용 재구성"으로 표기 — 지어낸 기사 없음.
- 미확정 내용은 점선 + "가설" 표기 유지 — 지우지 말 것.
